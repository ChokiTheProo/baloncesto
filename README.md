# Biblioteca Táctica de Baloncesto

Página de aterrizaje de la oferta de la Biblioteca Táctica de Baloncesto: 300 técnicas de baloncesto explicadas paso a paso, con app, PDF y plan de 30 días.

Es un sitio estático que se despliega en Vercel sin paso de build. No hay herramientas de compilación ni secretos en el repositorio.

Los enlaces de checkout y el ID del Meta Pixel están en `config.js`.

El CSS va inline en `index.html`. `styles.css` es la fuente legible de esos estilos.
